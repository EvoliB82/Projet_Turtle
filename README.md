# Comment utiliser le programme


## 1. Utiliser le programme

Le programme pose plusieurs questions dans la console :

- Le nombre de maisons (entre 1 et 4).
- Le nombre d'étages de chaque maison (entre 0 et 4).
- La couleur de la façade.
- La couleur de la porte.
- Le type de toit (triangle, plat ou ardc).
- La couleur du toit.

Il faut entrer les réponses dans la console et appuyer sur Entrée à chaque fois.

Les couleurs disponibles sont affichées dans la question. Il faut écrire l'une d'elles.

## 2. Résultat

Sur une fenêtre Turtle les maisons choisies se dessinent au fur et à mesure des réponses et des nuages qui se déplacent dans le ciel à la fin de l'exécution.

La fenêtre reste ouverte à la fin du programme. Il suffit de la fermer pour quitter.

## 3. À savoir

- Si une réponse n'est pas valide, le programme redemande une valeur.
- Le type de toit ardc correspond au toit arrondi (arc de cercle).
- Le module turtle est fourni avec Python. Aucun module supplémentaire n'est nécessaire pour ce programme.
